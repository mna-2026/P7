# P7 : Implémentez un modèle de scoring

* Le répertoire api contient
  * le code de l'API encapsulant, entre autres, la fonctionnalité d'inférence du modèle : api.py
  * les tests unitaires de l'API : test_api.py
  * les librairies nécessaires à l'API, avec l'indication des versions : requirements.txt

* Le répertoire streamlit contient
  * le code du dashboard streamlit interagissant avec l'API : app.py
  * les tests unitaires du dashboard : test_app.py
  * les librairies nécessaires, avec l'indication des versions : requirements.txt

* Le répertoire data contient le modèle et des données

* Le fichier Dockerfile décrit la construction de l'API via Docker

* Les workflows GitHub Actions se trouvent dans le répertoire .github/workflows
